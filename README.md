# Text-to-Speech Conversion

This is a Python-based Text-to-Speech (TTS) program that uses the `pyttsx3` library to convert text entered by the user into speech. It supports adjustable speech rate and the option to choose between a male or female voice for speech synthesis.

## Features

- **Text-to-Speech**: Converts entered text into speech.
- **Customizable Speech Rate**: Adjust the speed of the speech.
- **Voice Selection**: Choose between male or female voices.
- **Exit Command**: Type "exit" to terminate the program.
  
## Requirements

- Python 3.x
- `pyttsx3` library (Used for text-to-speech synthesis)
